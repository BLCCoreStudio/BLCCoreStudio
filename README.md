## ✦ About BLC Core Studio

**BLC Core Studio** builds practical developer tools with an emphasis on **repository intelligence, terminal productivity, automation, safety, and polished developer experience**.

This GitHub profile is the public home for product releases, open-source utilities, documentation, security guidance, and engineering work from BLC Core Studio.

The goal is simple: turn repetitive or error-prone engineering tasks into tools that feel clear, fast, dependable, and safe by default.

---

## 🚀 Flagship Projects

### 🩺 [RepoDoctor](https://github.com/BLCCoreStudio/RepoDoctor)

**Professional repository intelligence.**

Analyzes repository health across security, testing, documentation, CI/CD, dependencies, configuration, structure, and architecture — then turns findings into prioritized diagnostics.

`Repository Health` `Security` `CI/CD` `Diagnostics` `Automation`

[![RepoDoctor Release](https://img.shields.io/badge/Release-v0.1.1-7C3AED?style=for-the-badge&logo=github)](https://github.com/BLCCoreStudio/RepoDoctor/releases/tag/v0.1.1)

### ⌨️ [TermKeys](https://github.com/BLCCoreStudio/TermKeys)

**Safer, faster terminal shortcuts.**

A lightweight Linux utility for installing useful keyboard shortcuts with backups, conflict detection, diagnostics, safe writes, uninstall, and restore support.

## ✅ Engineering Standards

Public repositories are maintained with an emphasis on reproducible builds, automated checks, clear release artifacts, documented security reporting, and predictable command-line behavior.

For the Rust CLI projects, CI validates formatting, linting, and tests before changes are considered healthy. Release downloads include verification material where applicable so users can validate distributed binaries or archives.

No fabricated usage metrics, download counts, testimonials, or benchmark claims are used here. Project maturity and release status are stated directly in each repository.

## 🤝 Try, Report, Contribute

Each project repository is the source of truth for installation, usage, current status, release notes, contribution guidance, and security reporting.

- Browse all repositories: [github.com/BLCCoreStudio?tab=repositories](https://github.com/BLCCoreStudio?tab=repositories)
- Download published builds from each project's **Releases** page
- Report bugs through the relevant repository's **Issues** page
- Propose improvements through focused pull requests and follow each repository's `CONTRIBUTING.md` and CI requirements where available
- Follow each repository's `SECURITY.md` for vulnerability reports rather than public issue threads
