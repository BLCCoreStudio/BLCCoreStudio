## Engineering doctrine

<table>
<tr>
<td width="25%" valign="top"><strong>Evidence over claims</strong><br /><sub>Benchmarks, tests, receipts, and observable behavior before marketing language.</sub></td>
<td width="25%" valign="top"><strong>Local-first where it matters</strong><br /><sub>Keep sensitive or latency-critical workflows close to the user whenever practical.</sub></td>
<td width="25%" valign="top"><strong>Reproducible by design</strong><br /><sub>Deterministic CI, explicit release paths, and conservative compatibility promises.</sub></td>
<td width="25%" valign="top"><strong>Narrow, deliberate scope</strong><br /><sub>Prefer a sharp product boundary over a large feature surface with weak ownership.</sub></td>
</tr>
</table>
