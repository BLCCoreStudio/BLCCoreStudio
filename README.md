## Selected work

### [OpenDevIndex](https://github.com/BLCCoreStudio/OpenDevIndex)
A source-backed index of developer technologies. The project is built around structured entries, validation, independent module branches and reproducible publishing.

### [AgentContextMap](https://github.com/BLCCoreStudio/AgentContextMap)
A local, read-only tool for seeing what instructions actually affect a coding agent inside a repository — including conflicts, scope and precedence.

### [RepoDoctor](https://github.com/BLCCoreStudio/RepoDoctor)
Repository health checks with actionable findings and optional CI gates. It is also available as a GitHub Marketplace Action.
